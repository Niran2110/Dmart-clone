# 🛒 DMart Ready - Grocery Website Clone

A responsive **DMart Ready grocery shopping website clone** developed using **HTML, CSS, and JavaScript**.

This project was created as part of my **Java Full Stack Development course at SevenMentor Training and Placement**.

## 📌 Project Overview

This project is a frontend clone inspired by the DMart Ready grocery shopping website.

It includes a main grocery shopping page and a dedicated **Biscuits & Cookies** product page with product listings and shopping-cart interactions.

## ✨ Features

### 🏠 Main Grocery Page

- DMart Ready header and navigation
- Delivery location popup
- Login / Register popup
- Search functionality
- Notification drawer
- Shopping cart drawer
- Automatic hero banner slider
- Popular categories section
- Category navigation
- Responsive website layout

### 🍪 Biscuits & Cookies Page

- 50 biscuit and cookie products
- Product images
- Product names
- MRP and selling price
- Discount information
- Product weight / variants
- Search functionality
- Add to Cart functionality
- Increase / decrease product quantity
- Shopping cart
- Cart total calculation
- Location popup
- Login popup
- Notification drawer

## 🛠️ Technologies Used
